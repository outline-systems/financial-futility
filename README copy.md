# Personal Finance — cleaned visual build

Upload `index.html` to the root of the GitHub repository, replacing the current file.

The app defines the requested font families as its first preference:
- TT Supermolot Neue Condensed (interface and values)
- Game Station Condensed (labels and system headers)

For exact font rendering on GitHub Pages/iPhone, add licensed webfont files later. Until then, the browser will fall back to condensed fonts if these are not locally installed.

This is a local-first app. Export a JSON backup regularly. Do not commit confidential bank/legal/court/title documents or backups to a public repository.
