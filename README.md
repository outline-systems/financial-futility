# Personal Finance — Local-first GitHub Pages app

## Publish
1. Create a new **private** GitHub repository, e.g. `personal-finance`.
2. Upload `index.html` from this package to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main`, and `/ (root)`, then Save.
4. Open the Pages URL. On iPhone use Safari → Share → **Add to Home Screen**.

## Important privacy note
This is a local-first application: records are stored in the browser on the device where you use it. Use **Settings → Export JSON backup** regularly.

Do not commit legal documents, bank statements, identity records, VRO/court material, title documents, or other confidential material to a public GitHub repository. The Documents & Evidence page is a metadata register, not secure cloud document storage.

## Contents
- `index.html`: complete standalone app
- No build process required
